# job-hunter

Radar de vagas com IA: coleta vagas de estágio, trainee e júnior, calcula o match
com o meu perfil, prepara currículo e respostas e registra tudo em planilha.
Nenhuma candidatura é enviada sem a minha aprovação (bot no Telegram).

## Roadmap
- [ ] Coletores de vagas
- [ ] Match com o perfil
- [ ] Comparativo com custo de vida
- [ ] Currículo e respostas por vaga
- [ ] Fila de aprovação no Telegram
- [ ] Planilha e acompanhamento de etapas
